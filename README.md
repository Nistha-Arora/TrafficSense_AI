# TrafficSense_AI
A machine learning-based traffic volume prediction system built with Python and Streamlit, using weather conditions and time-based features to predict traffic levels with interactive visualizations.
🚦 TrafficSense AI – Traffic Volume Prediction

📌 About the Project

TrafficSense AI is a machine learning-based project designed to predict traffic levels using time-based and weather-related data. The project uses Python and a Streamlit web application to provide interactive traffic predictions.

✨ Features

- Predict traffic levels using time and weather information
- Input temperature, rainfall, snowfall, and cloud coverage
- Machine learning-based prediction
- Interactive web interface using Streamlit
- Simple and user-friendly design

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Streamlit

📂 Project Structure

TrafficSense/

📊 Dataset

This project uses the Metro Interstate Traffic Volume dataset, which contains historical traffic volume and weather information.

⚙️ Installation and Setup

1. Clone the repository

git clone YOUR_REPOSITORY_URL

2. Open the project folder

cd TrafficSense

3. Install the required libraries

python -m pip install -r requirements.txt

4. Run the Streamlit application

python -m streamlit run app.py

The main objective of TrafficSense AI is to explore traffic patterns and predict traffic levels using machine learning and weather-related features.
